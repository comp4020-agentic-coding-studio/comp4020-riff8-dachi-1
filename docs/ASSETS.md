# Assets

Every picture and sound in Plenty is generated by code in this repository. There are no image, audio, model or font files, so there's nothing to license and nothing to download at runtime. Three.js (MIT) is the only rendering dependency.

| Asset | Where | Notes |
| --- | --- | --- |
| terrain, water, stellar core, remnant ground, sky | `client/render3d.ts` | per-world palettes in `STAGES[].palette` (`shared/content.ts`); ground colour interpolates "dead" to "lush" by tile life; terrain tiles and props are instanced |
| deposits (trees and stumps, rocks, ice, plasma, asteroids, galaxies) | `client/models.ts` | low-poly geometry built in code; size and foliage follow remaining stock |
| buildings, including workbench, campfire and chest | `client/models.ts` | one model per building type, with scaffolding for sites under construction |
| avatars, held tools, first-person hands | `client/models.ts` | colours in `PLAYER_COLOURS` (`client/view.ts`) |
| wildlife (deer, rabbit, boar, wolf, heron, fish), death bags | `client/models.ts` | a carcass lies on its side |
| names and labels | `client/render3d.ts` | DOM text (`textContent`), never HTML |
| emote glyphs | system emoji font | 👋 💛 😄 😮 😢 👉 |
| interface | `app/globals.css` | system rounded sans (`ui-rounded`, falling back to `system-ui`) |
| music, ambience, effects | `client/audio.ts` | Web Audio oscillators and filtered noise: pentatonic (Earth, Mars) and minor (later worlds) plucks, a pad, birdsong, wind and water noise, a machine hum, harvest/build/reject/transition tones |

## Replacing or extending them

- **A model**: each builder in `client/models.ts` returns a `THREE.Object3D` from cached geometries and materials; swap its body, or load a glTF once and clone it there.
- **A world's look**: edit its `palette` in `shared/content.ts`.
- **Sound**: `Sound` exposes `harvest()`, `build()`, `reject()` and `boundary()`; replace their bodies with `AudioBufferSourceNode`s routed to the same bus to keep the volume controls working.
